Session Alive 已安装

感谢安装 Session Alive 扩展！创建规则以保持您的会话活跃！

快速开始

  1. 登录您的网站并导航到仪表板/欢迎页面
  2. 点击浏览器工具栏或扩展菜单或溢出菜单中的 Session Alive 扩展图标 。
  3. 点击 按钮。
  4. 页面重新加载，您的会话现已活跃！

使用方法

  1. 登录您的网站并复制仪表板/欢迎 URL
  2. 您可以点击 按钮来快速创建规则。
  3. 点击 来管理规则。
  4. 点击 按钮来添加新规则，将复制的 URL 粘贴到 Background Request Options → Trigger URL
  5. 根据需要设置请求间隔，然后点击 按钮保存。
  6. 点击保存成功消息中的 Trigger URL 链接。Navigate to Trigger URL to start the Rule.
  7. 您也可以刷新仪表板/欢迎 URL 或再次登录
  8. 您的会话现已活跃！

快速提示

管理您的规则以保持您的会话活跃！：

  • 规则名称：输入一个描述性名称来标识您的规则。
  • 触发 URL：访问此 URL 时，将启动后台请求过程。
  • 请求间隔：指定后台请求的频率。
