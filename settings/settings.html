帮助与信息

管理您的规则以保持会话活跃！

  • 规则名称：输入描述性名称来标识您的规则。
  • 触发 URL：访问此 URL 时将启动后台请求过程。
  • 请求间隔：指定后台请求的频率。

点击侧边栏中的规则进行编辑或删除，或使用"添加新规则"按钮创建新规则。

添加新规则

有效的触发 URL （包含 "http://" 或 "https://"）是必需的。
某些网站实现了 JavaScript 空闲计时器。对于这些网站，在后台请求页面 不足以保持会话活跃。页面需要重载以保持会话。导航到任何以触发 URL 开头的 URL 将启动前台页面重载循环。例如，触发 URL 设置为 https://example.com/user/，导航到 https://example.com/user/profile 或 https://example.com/user/account/details 将设置为 按设定间隔自动重载。
